# Auto Mode Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a global auto mode switch that automatically chains OCR extraction, LLM customs draft mapping, and customs-site submission for new tasks.

**Architecture:** Persist the auto mode flag alongside existing LLM settings, then extend the extraction async task so that after history persistence it optionally generates a submission draft and attempts customs submission. The frontend settings page manages the switch, and the task/result UI shows the extra stages and outcomes.

**Tech Stack:** FastAPI, Python 3.11, Vue 3, Element Plus, Vite, pytest, Vitest
