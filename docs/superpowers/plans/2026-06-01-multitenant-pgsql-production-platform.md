# Multitenant PostgreSQL Production Platform Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert TeleIDP into a production-grade multitenant SaaS platform backed by PostgreSQL, with a stable scoped API surface for future agent skill calls.

**Architecture:** Use one shared PostgreSQL database with mandatory `tenant_id` on tenant-owned tables and PostgreSQL RLS as a database-level safety net. Browser routes keep the current `/api/...` shape during migration, while repositories and tenant context are introduced underneath; machine clients use a separate `/api/v1/agent/...` API with API keys, scopes, idempotency, and audit logs.

**Tech Stack:** FastAPI, Vue/Vite, PostgreSQL, SQLAlchemy 2.x, Alembic, psycopg 3, uv-managed Python environment, pytest, npm/Vitest.

---

## Scope

This is a platform migration, so implementation must land in testable slices:

1. Foundation: dependency metadata, config, DB session, models, migrations, tenant context, API key primitives.
2. Data migration: import current file-backed `output/` data into the default tenant without deleting existing files.
3. Repository migration: move templates, LLM settings, history metadata, and task records behind tenant-aware repositories.
4. Agent API: add scoped `/api/v1/agent/...` endpoints for extraction, polling, template reads, and history reads.
5. Production hardening: health checks, audit logs, rate limits, deployment docs, backups, object storage abstraction.

Do not try to complete all five slices in one unsafe refactor. Each task below should pass before moving on.

```python
from __future__ import annotations

import os
from dataclasses import dataclass


@dataclass(frozen=True)
class AppSettings:
    app_name: str = "TeleIDP"
    environment: str = os.getenv("APP_ENV", "development")
    database_url: str = os.getenv(
        "DATABASE_URL",
        "postgresql+psycopg://teleidp:teleidp@127.0.0.1:5432/teleidp",
    )
    default_tenant_slug: str = os.getenv("DEFAULT_TENANT_SLUG", "default")
    api_key_prefix: str = os.getenv("API_KEY_PREFIX", "tidp")
    secret_key: str = os.getenv("SECRET_KEY", "")
    local_asset_root: str = os.getenv("LOCAL_ASSET_ROOT", "output/tenants")

    def validate_for_startup(self) -> list[str]:
        errors: list[str] = []
        if self.environment == "production":
            if not self.database_url:
                errors.append("DATABASE_URL is required in production")
            if not self.secret_key:
                errors.append("SECRET_KEY is required in production")
        return errors


def get_settings() -> AppSettings:
    return AppSettings()
```
