到货单智能抽取中台 - 用户使用说明

1. 系统简介

本系统用于对 PDF、图片、Office 单据进行自动识别，并提取结构化字段结果。核心流程为：上传文件 -> 后台提取 -> 在结果中心查看进度和结果。

2. 登录后主要页面

  • 模板管理：维护不同厂商、单据类型的字段与规则。
  • 提取工作台：上传文件并发起提取任务。
  • 结果中心：查看后台任务进度、历史记录、识别字段和 Markdown / 文本预览。

3. 快速使用（推荐）

  1. 进入 提取工作台，选择厂商和单据类型。
  2. 上传一个文件（支持 PDF、图片、Word、PPT）。
  3. 确认提示词后点击 开始提取。
  4. 系统自动跳转到 结果中心，任务在后台执行。
  5. 任务完成后，在左侧历史记录选择最新记录查看结果。

4. 结果中心说明

4.1 任务与历史

  • 刷新任务：更新后台任务状态。
  • 刷新历史：更新历史记录列表。
  • 下载 JSON：下载当前选中记录的提取结果。

4.2 字段结果区

  • 上半部分（字段名区域）：点击后可在预览区自动定位对应内容。
  • 下半部分（值区域）：可直接选择文本并复制，不会触发跳转。
  • 布局会随窗口宽度自动调整，一行可显示多个字段卡片。

4.3 Markdown / 文本预览

  • 显示PDF解析与系统整理后的预览内容。
  • 支持展开/收起，也支持全屏查看。

5. 扫描件方向自动修正

系统在 解析PDF 前，会尝试自动纠正页面方向（基于 Tesseract OSD），适用于扫描件倾斜、横向、倒置等情况，尤其是“不同页方向不一致”的文档。

  • 自动修正失败时会回退原文件继续处理，不会中断任务。
  • 若仍有个别页异常，建议先人工旋转后再上传。

6. 模板管理建议

  • 字段名尽量清晰稳定（如：发票号、到货日期、净重）。
  • 提示词建议明确 JSON 结构，减少返回波动。
  • 对固定区域字段可使用 region_rules 提高稳定性。

7. 常见问题

Q1：点击开始提取后没立即出结果？

任务为后台执行，请在结果中心查看进度，完成后再查看结果。

Q2：预览有乱码或不完整？

  • 先确认是否是扫描件质量问题（模糊、倾斜、遮挡）。
  • 可重试一次，系统会自动做方向修正。
  • 必要时先对原始文件做清晰化或旋转后再上传。

Q3：为什么历史里有多条同名文件？

每次提取都会生成独立历史记录，便于回溯和对比。

8. 操作注意事项

  • 建议单次只上传一个文件，便于追踪任务和结果。
  • 大文件处理时间会更长，请耐心等待任务完成。
  • 删除历史后不可恢复，请确认后再删除。

9. 联系支持

如遇持续异常，建议反馈以下信息：

  • 文件名
  • 提取时间
  • 结果中心历史记录 ID（如有）
  • 异常现象截图
